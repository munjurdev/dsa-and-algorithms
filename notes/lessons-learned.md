# Lessons Learned

Long-form reflections — the insights that don't fit in a solution docstring.
One entry per session or per hard-won problem. Append at the bottom; never
edit history (a changed understanding is a *new* entry).

## Entry format

```markdown
### YYYY-MM-DD — <Day NNN> — <short title>
- **Problem(s):** <names>
- **What I understood:** <the insight, in plain language>
- **What I got wrong first:** <the false belief>
- **Pattern:** <which entry from problem-solving-patterns.md>
- **Review by:** <date>
```

## Prompts when stuck for something to write

- What would make me recognize this problem type faster next time?
- Which invariant was I missing?
- What did the constraints tell me that I ignored?
- If I explained this to a beginner, which sentence would break down?
- What trade-off (time vs space, clarity vs cleverness) did I choose, and was
  it the right one here?
