# 27 — Patterns and Revision

> Phase 10 · Roadmap Days 178–180 · Folder: `27-patterns-and-revision/`

The capstone: stop learning new topics and make everything already learned
**retrievable under time pressure**.

## Purpose

Interview performance is recall speed plus composure, not topic coverage.
This folder holds the consolidation material: pattern drills, timed mixed
sets, mock-interview write-ups, and the final revision plan you keep using
after Day 180.

## Core concepts

| Concept | Idea in one line | Must be able to... |
|---|---|---|
| Pattern retrieval | map problem → pattern in < 2 minutes | use `notes/problem-solving-patterns.md` as a checklist |
| Timed practice | 25 min medium, 40 min hard, closed notes | finish with a clean complexity statement |
| Blind re-solve | solve from a blank file without looking | prove retention, not recognition |
| Mock interviews | think aloud, code, test, defend complexity | run one end-to-end session |
| Spaced repetition | revisit weak topics at 1 / 7 / 30 days | maintain `PROGRESS.md` review columns |

## Key patterns

1. **Difficulty ladder** — easy (warm-up) → medium (core) → hard (stretch)
   within one theme.
2. **Identify-first drills** — read the statement, name the pattern and the
   expected complexity *before* coding; check yourself after.
3. **Weakness log** — every failed problem from `notes/common-mistakes.md`
   gets a re-solve in 7 days.

## Complexity expectations

- Not a topic of its own: this folder exists to *re-derive* complexity
